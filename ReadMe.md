🚇 Baku Metro 2024
Этот проект моделирует движение поездов по линиям метро с использованием многопоточности и синхронизации в C++. Каждый поезд двигается по своей линии, останавливается на станциях, ожидает, и разворачивается в конце маршрута.

📄 Описание структуры и компонентов
1. Станции метро (allStations)
   cpp
   Копировать
   Редактировать
   std::vector<std::string> allStations = { "Icherisheher", "Sahil", ..., "Khatai" };
   Список всех станций метро, используемых в проекте.

2. Сопоставление станций и их индексов
   cpp
   Копировать
   Редактировать
   std::map<std::string, int> stationIndex;
   Создаёт удобный способ обращаться к индексам станций по их названию.

3. Мьютексы для синхронизации поездов на станциях
   cpp
   Копировать
   Редактировать
   std::vector<std::unique_ptr<std::mutex>> stationMutexes;
   Каждая станция имеет свой mutex, чтобы избежать конфликта при одновременном прибытии нескольких поездов.

4. Структура Line
   cpp
   Копировать
   Редактировать
   struct Line {
   std::string name;
   std::vector<int> stationIndices;
   };
   Объект, представляющий одну линию метро — содержит имя и список индексов станций.

5. Инициализация линий метро (initializeLines)
   cpp
   Копировать
   Редактировать
   void initializeLines();
   Заполняет карту stationIndex

Инициализирует stationMutexes

Создаёт четыре линии: Red, Green, Violet и Lime с соответствующими станциями.

6. Функция train — логика поезда
   cpp
   Копировать
   Редактировать
   void train(int train_id, const Line& line, bool direction);
   train_id: идентификатор поезда

line: линия метро, по которой движется поезд

direction: направление движения (вперёд или назад)

Функция реализует:

захват мьютекса станции

сообщение о прибытии и отправлении

задержку (остановку) на станции

разворот в конце маршрута

7. Функция sleep_ms
   cpp
   Копировать
   Редактировать
   void sleep_ms(int ms);
   Обёртка над std::this_thread::sleep_for, позволяет делать паузы в миллисекундах.

8. Главная функция (main)
   cpp
   Копировать
   Редактировать
   int main();
   Инициализирует линии

Создаёт и запускает потоки поездов для каждой линии

Использует join() для ожидания завершения всех потоков (в данном случае — бесконечный цикл).

🧵 Многопоточность и синхронизация
Каждый поезд запускается в своём потоке.

Для каждой станции используется индивидуальный mutex.

coutMutex — защищает вывод в консоль от смешивания сообщений разных потоков.
